# پروژه امیدوار — نسخه آماده‌سازی‌شده

این بسته شامل سرور FastAPI، رابط وب در `static/` و سورس برنامه اندروید در `android-app-source/` است.

## اصلاحاتی که انجام شده
- ساختار `static/` بررسی و نگه‌داری شده است؛ فایل‌های رابط وب در مسیر مورد انتظار سرور هستند.
- Dockerfile برای کپی فایل‌های سرور و اجرای برنامه روی پورت 7860 تنظیم شده است.
- پورت `docker-compose.yml` با پورت 7860 هماهنگ شده است.
- کانتینر با کاربر غیرریشه اجرا می‌شود و پایگاه داده در مسیر پایدار `/app/data/omidwar.db` قرار می‌گیرد.

## موارد ضروری پیش از انتشار عمومی
این موارد به حساب میزبانی و تنظیمات محرمانه‌ای نیاز دارند که فقط مالک حساب باید انجام دهد:

1. پروژه را در یک میزبان پشتیبان Docker (برای نمونه Hugging Face Spaces با SDK نوع Docker) منتشر کنید.
2. در تنظیمات محرمانه میزبان این متغیرها را با مقادیر قوی و تصادفی تنظیم کنید:
   - `ADMIN_USER`
   - `ADMIN_PASSWORD` (رمز قوی و منحصربه‌فرد)
   - `TOKEN_SECRET` (حداقل ۳۲ نویسه تصادفی)
   - `DATABASE_PATH=/app/data/omidwar.db`
3. برای حفظ اطلاعات، فضای ذخیره‌سازی پایدار را به `/app/data` متصل کنید.
4. پس از انتشار، نشانی HTTPS واقعی را باز کنید و مطمئن شوید مسیر `/health` پاسخ `{"ok":true,...}` می‌دهد.
5. در `android-app-source/app/src/main/java/com/omidwar/app/MainActivity.java` مقدار `APP_URL` را با نشانی HTTPS واقعی جایگزین کنید.
6. پروژه `android-app-source` را در Android Studio باز کنید، Gradle Sync انجام دهید و APK را بسازید. برای انتشار عمومی باید APK با کلید امضای اختصاصی امضا شود.

## نکات امنیتی
- فایل `.env` واقعی، رمزها، کلید امضای اندروید و رمز آن را در GitHub یا داخل این ZIP قرار ندهید.
- ارسال پیامک به‌صورت پیش‌فرض خاموش است (`SMS_ENABLED=false`). بدون رضایت و آزمایش سرویس پیامک آن را روشن نکنید.
- پیش از واردکردن اطلاعات واقعی دانش‌آموزان، مجوزها و الزامات حریم خصوصی محل استفاده را بررسی کنید.

## اجرای محلی با Docker Compose
یک فایل `.env` محلی بر اساس `.env.example` بسازید و مقادیر محرمانه را تنظیم کنید؛ سپس:

```bash
docker compose up --build
```

برنامه در `http://localhost:7860` در دسترس خواهد بود.

## وضعیت APK
سورس اندروید موجود است، اما APK نهایی هنوز ساخته نشده؛ زیرا برنامه باید به نشانی HTTPS واقعی سرور متصل شود و این محیط Android SDK/Gradle نصب‌شده برای ساخت APK ندارد.
